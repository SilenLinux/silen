Silen Linux

Independent • Minimal • AGPLv3

Built from the ground up

Silen Linux is an independent distribution. It is not a remix of another system — the builder, live init, installer, and package manager are all developed in-house.

The goal is a minimal, clean base you build on. InstantWM is the default desktop, and you can install alternatives through CRES after installation.

Features

CRES package manager

A purpose-built package manager for Silen Linux. System packages install into /; applications stay isolated from the core system.

Own init system

OpenRC with elogind — not a remixed stack. The live environment and installed system both use Silen’s own init.

Offline text-menu installer

A fully offline installer that finds the install medium itself, followed by the silen-setup wizard on first boot.

InstantWM desktop

InstantWM is the default desktop environment. The base remains minimal and you can install alternatives through CRES.

Broad hardware support

In-tree drivers and firmware for storage, Wi-Fi, and GPUs (amdgpu, i915, xe, nouveau, radeon) ship on the ISO.

Linux 6.18 kernel

Kernel 6.18.54 on x86_64, UEFI only, with GRUB2. Root on ext4, btrfs, or fat32.

Development status

Under active development

Silen Linux is not yet ready for a public stable release. The project is actively being developed, and mainline ISO images are currently unavailable.

  • Mainline standard and NVIDIA ISOs — currently unavailable

Follow development and view the source at github.com/SilenLinux/SilenLinux.
