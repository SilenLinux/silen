Features

📖

Own package manager

spk, a single Rust binary with no daemon. System packages install into /; leaf apps stay isolated under /spk_pkgs.

💡

Own init system

OpenRC + elogind — not a remixed stack. The live init and installed system are Silen’s own.

✉

Offline installer

A fully text-menu based installer that finds the install medium itself, followed by the silen-setup wizard on first boot.

🏠

No forced desktop

A minimal live environment that installs a clean base. You choose the desktop, login manager, and extras during setup.

🛠

Broad hardware support

In-tree drivers and firmware for storage, Wi-Fi, and GPUs (amdgpu, i915, xe, nouveau, radeon) ship on the ISO.

📙

Kernel 6.18

Linux 6.18.54 on x86_64, UEFI only, with GRUB2. Root on ext4, btrfs, or fat32.

About Silen

Silen Linux is an independent, lightweight Linux distribution. It is not a remix of another distribution — the builder, live init, installer, and package manager are all developed in-house.

The goal is a minimal, clean base you build on. There is no forced desktop and no bloat. After installation, the silen-setup wizard lets you choose your desktop, login manager, firmware, and extras.

The project is licensed under AGPLv3 and development happens in the open on GitHub.

Development Status

Under active development

Silen Linux is not yet ready for a public stable release. The project is actively being developed, and ISOs are not currently available for the mainline standard or NVIDIA variants.

  • Mainline standard and NVIDIA ISOs — currently unavailable
  • Silen Arch (Arch Linux base) — available
  • Silen Void (Void Linux base with runit) — available
  • Silen Debian (Debian base) — coming soon

Follow development and view the source at github.com/Cgtlpa/SilenLinux.
