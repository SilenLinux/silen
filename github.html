Source code

Silen Linux is developed in the open. The builder, live init system, installer, CRES package manager, and this website are all hosted in the public repository:

View on GitHub

The project is licensed under AGPLv3. Contributions, bug reports, and feedback are welcome through GitHub issues and pull requests.

What’s in the repository

  • Builder — constructs the live ISO and installed base system
  • Live init — OpenRC + elogind for the live environment
  • Installer — offline text-menu installer with silen-setup first-boot wizard
  • Package manager — CRES, the Silen Linux package manager
  • Website — this site, served at https://cgtlpa.github.io/silen/
