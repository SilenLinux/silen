CRES package manager

CRES is the Silen Linux package manager. It handles system packages and software installation for Silen Linux. Packages are built and maintained specifically for the distribution — this is not a remixed stack.

After installation, the silen-setup wizard installs your desktop, login manager, firmware, and extras through CRES.

Repository highlights

Kernels & graphics — linux-6.18, linux-firmware, nvidia-drivers, mesa, the full xorg stack.

Desktops & Wayland — instantwm, dwm, niri, waybar, rofi, mako.

Login — sddm, ly, greetd + tuigreet, seatd.

Shells, editors & terminals — fish, zsh, starship; vim, neovim, helix; kitty, alacritty, tmux.

Everyday CLI — fastfetch, htop, btop, git, gh, lazygit, eza, bat, ripgrep, fzf.

System & network — btrfs-progs, cryptsetup, smartmontools, sensors, efibootmgr, iwtui, openssh, chrony.
